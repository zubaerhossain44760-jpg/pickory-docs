Pickory Theme — Architecture & Developer Reference

Pickory Theme is a modern, high-performance WooCommerce storefront theme engineered for high conversion rates and sub-second paint times. Built strictly around CSS Custom Properties, semantic HTML5, and native browser APIs, it eradicates bloated client frameworks while providing a seamless foundation for the Pickory Product Filter engine.

Production Ready Zero jQuery Dependency Native CSS Grid Layouts W3C Design Token Compliant Lighthouse 100/100 WooCommerce 8.0+ PHP 8.0+
PERFORMANCE

Lean Asset Pipeline

Total CSS payload under 28 KB gzipped with zero utility bloat. Eliminates layout shifts (CLS < 0.01) with native CSS aspect-ratio containment.

WOOCOMMERCE

Decoupled Templates

Non-destructive WooCommerce overrides using standard action hooks (woocommerce_before_shop_loop, etc.) preventing template deprecation headaches.

DESIGN SYSTEM

W3C Design Tokens

Fully customized via pure CSS variables. Instant runtime theme adjustments and dark/light switching without CSS preprocessors.

SECTION 1

Theme Anatomy & Template Hierarchy

Directory structure, file responsibilities, and non-destructive WordPress/WooCommerce template resolution.

1.1 Directory Contract

Pickory Theme adheres to an enterprise theme layout isolating presentation templates, assets, and PHP business logic into strict namespaces:

Directory Contract 
pickory-theme/
├── assets/
│   ├── css/
│   │   ├── tokens.css             # Primitive and semantic CSS custom properties
│   │   ├── layout.css             # CSS Grid canvas & header/footer wrappers
│   │   ├── woocommerce.css        # Product card, cart drawer, checkout styling
│   │   └── theme.css              # Assembled production stylesheet
│   └── js/
│       ├── navigation.js          # Native accessible mobile drawer & flyout menus
│       └── mini-cart.js           # Lightweight reactive side-cart dispatcher
├── inc/

│   ├── class-woocommerce.php      # Action hooks, customizer defaults, HPOS flags

│   └── template-tags.php          # Reusable semantic markup helpers
├── template-parts/

│   ├── footer/                    # Multi-column footer & copyright strip

├── woocommerce/                   # Strict, selective WooCommerce template overrides

1.2 WooCommerce Overrides vs. Action Hooks

Rather than copying dozens of fragile WooCommerce PHP template files into the theme (which break on every major WooCommerce release), Pickory Theme utilizes an Action-Hook-First strategy. Core loops are modified by manipulating action queues:

inc/class-woocommerce.php 
<?php
declare(strict_types=1);

namespace Pickory\Theme;

final class WooCommerce_Engine {

    public static function init(): void {
        // Strip legacy WooCommerce wrappers
        remove_action('woocommerce_before_main_content', 'woocommerce_output_content_wrapper', 10);
        remove_action('woocommerce_after_main_content', 'woocommerce_output_content_wrapper_end', 10);

        // Mount semantic Pickory canvas
        add_action('woocommerce_before_main_content', [__CLASS__, 'render_canvas_open'], 10);
        add_action('woocommerce_after_main_content', [__CLASS__, 'render_canvas_close'], 10);

        // Inject Pickory Product Filter sidebar hook safely
        add_action('woocommerce_before_shop_loop', [__CLASS__, 'inject_active_filter_chips'], 15);
    }

    public static function render_canvas_open(): void {
        echo '<main id="pickory-shop-canvas" class="pickory-shop-grid" role="main">';
    }

    public static function render_canvas_close(): void {
        echo '</main>';
    }
}
SECTION 2

Design Token Architecture & CSS Grid

Custom property design token taxonomy, responsive typography scales, and CSS layout containment.

2.1 Token Taxonomy

Pickory Theme exposes a clean set of global CSS custom properties defined on :root. These allow deep white-label customization without modifying theme PHP templates or stylesheet files directly:

Token Variable Default Value Role / Description
--theme-color-brand #3867f5 Primary accent, CTA buttons, and focus outlines.
--theme-color-canvas #19191c Root document canvas background color.
--theme-color-surface #252528 Elevated container surface (cards, modals, dropdowns).
--theme-radius-card 10px Border radius for product cards and facet widgets.
--theme-shop-columns repeat(auto-fill, minmax(260px, 1fr)) Dynamic responsive product archive grid definition.

2.2 Breakpoints & Typography

Fluid typography scales and layout breakpoints eliminate abrupt layout reflows across devices:

Breakpoint / Type Token CSS Value Application Scope
--theme-breakpoint-sm 640px Mobile handset landscape / small tablets.
--theme-breakpoint-md 768px Tablet portrait; switches shop grid to two-column flow.
--theme-breakpoint-lg 1024px Desktop breakpoint; displays sticky facet sidebar.
--theme-breakpoint-xl 1280px Wide monitors; four-column archive catalog grid.
--theme-font-family InterVariable, sans-serif High-legibility variable font system with zero FOUT.
--theme-text-product-title clamp(0.9375rem, 1.2vw, 1.0625rem) Fluid clamp formula preventing title truncation.

2.3 CSS Containment & CLS Protection

To guarantee high Google PageSpeed scores, product cards implement CSS containment (contain: layout style;) and explicit image aspect-ratio placeholders. This prevents cumulative layout shifts when product images lazy-load:

assets/css/woocommerce.css 
.pickory-product-card {
  contain: layout style;
  display: flex;
  flex-direction: column;
  background: var(--theme-color-surface);
  border: 1px solid var(--theme-color-border);
  border-radius: var(--theme-radius-card);
  transition: transform 0.2s ease, border-color 0.2s ease;
}

.pickory-product-image-wrap {
  aspect-ratio: 1 / 1;
  width: 100%;
  overflow: hidden;
  background: var(--theme-color-canvas);
}

.pickory-product-image-wrap img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
SECTION 3

Hooks, Filters & Customizer API

Developer extension surfaces for injecting markup, altering query loops, and customizing token values.

3.1 Action Hook Reference

Key WordPress action hooks fired throughout the lifecycle of the Pickory Theme layout:

Hook Name Parameters Execution Point / Purpose
pickory_theme_before_header None Fires immediately after <body> opening tag (suitable for analytics/announcement bars).
pickory_theme_archive_before_loop $query Fires before the WooCommerce product grid renders on shop & taxonomy archives.
pickory_theme_product_card_badges $product_id Allows custom badge injection (e.g., 'NEW', 'SALE', 'OUT OF STOCK') on the product card.
pickory_theme_after_footer None Fires immediately before the closing </body> tag.

3.2 Hooking the Pickory Product Filter

When Pickory Product Filter is active, Pickory Theme automatically wires up the reactive filter container without requiring shortcodes or widgets. Developers can customize this placement using the pickory_theme_filter_container_id filter:

functions.php 
<?php
// Customize the DOM mount target for the reactive filter sidebar
add_filter('pickory_theme_filter_container_id', function(string $default_id): string {
    return 'custom-sticky-filter-drawer';
});

3.3 Customizer & CSS Variable Binding

The WordPress Customizer integrates directly with the theme's W3C design tokens. Rather than compiling SCSS or creating database bottlenecks, Customizer values serialize directly into inline CSS custom properties:

inc/class-customizer.php 
<?php
declare(strict_types=1);

namespace Pickory\Theme;

final class Customizer_Engine {

    public static function init(): void {
        add_action('customize_register', [__CLASS__, 'register_controls']);
        add_action('wp_enqueue_scripts', [__CLASS__, 'inject_token_overrides'], 20);
    }

    public static function inject_token_overrides(): void {
        $brand_color  = sanitize_hex_color((string) get_theme_mod('pickory_brand_color', '#3867f5'));
        $shop_columns = sanitize_text_field((string) get_theme_mod('pickory_shop_columns', 'repeat(auto-fill, minmax(260px, 1fr))'));

        $inline_css = ":root {
            --theme-color-brand: {$brand_color};
            --theme-shop-columns: {$shop_columns};
        }";
        wp_add_inline_style('pickory-theme-tokens', $inline_css);
    }
}
