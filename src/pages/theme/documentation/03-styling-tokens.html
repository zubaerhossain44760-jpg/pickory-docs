SECTION 2

Design Token Architecture & CSS Grid

Custom property design token taxonomy, responsive typography scales, and CSS layout containment.

2.1 Token Taxonomy

Pickory Theme exposes a clean set of global CSS custom properties defined on :root. These allow deep white-label customization without modifying theme PHP templates or stylesheet files directly:

Token Variable Default Value Role / Description
--theme-color-brand #3867f5 Primary accent, CTA buttons, and focus outlines.
--theme-color-canvas #19191c Root document canvas background color.
--theme-color-surface #252528 Elevated container surface (cards, modals, dropdowns).
--theme-radius-card 10px Border radius for product cards and facet widgets.
--theme-shop-columns repeat(auto-fill, minmax(260px, 1fr)) Dynamic responsive product archive grid definition.

2.2 Breakpoints & Typography

Fluid typography scales and layout breakpoints eliminate abrupt layout reflows across devices:

Breakpoint / Type Token CSS Value Application Scope
--theme-breakpoint-sm 640px Mobile handset landscape / small tablets.
--theme-breakpoint-md 768px Tablet portrait; switches shop grid to two-column flow.
--theme-breakpoint-lg 1024px Desktop breakpoint; displays sticky facet sidebar.
--theme-breakpoint-xl 1280px Wide monitors; four-column archive catalog grid.
--theme-font-family InterVariable, sans-serif High-legibility variable font system with zero FOUT.
--theme-text-product-title clamp(0.9375rem, 1.2vw, 1.0625rem) Fluid clamp formula preventing title truncation.

2.3 CSS Containment & CLS Protection

To guarantee high Google PageSpeed scores, product cards implement CSS containment (contain: layout style;) and explicit image aspect-ratio placeholders. This prevents cumulative layout shifts when product images lazy-load:

assets/css/woocommerce.css 
.pickory-product-card {
  contain: layout style;
  display: flex;
  flex-direction: column;
  background: var(--theme-color-surface);
  border: 1px solid var(--theme-color-border);
  border-radius: var(--theme-radius-card);
  transition: transform 0.2s ease, border-color 0.2s ease;
}

.pickory-product-image-wrap {
  aspect-ratio: 1 / 1;
  width: 100%;
  overflow: hidden;
  background: var(--theme-color-canvas);
}

.pickory-product-image-wrap img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
