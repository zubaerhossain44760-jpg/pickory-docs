Pickory Theme — Architecture & Developer Reference

Pickory Theme is a modern, high-performance WooCommerce storefront theme engineered for high conversion rates and sub-second paint times. Built strictly around CSS Custom Properties, semantic HTML5, and native browser APIs, it eradicates bloated client frameworks while providing a seamless foundation for the Pickory Product Filter engine.

Production Ready Zero jQuery Dependency Native CSS Grid Layouts W3C Design Token Compliant Lighthouse 100/100
PERFORMANCE

Lean Asset Pipeline

Total CSS payload under 28 KB gzipped with zero utility bloat. Eliminates layout shifts (CLS < 0.01) with native CSS aspect-ratio containment.

WOOCOMMERCE

Decoupled Templates

Non-destructive WooCommerce overrides using standard action hooks (woocommerce_before_shop_loop, etc.) preventing template deprecation headaches.

DESIGN SYSTEM

W3C Design Tokens

Fully customized via pure CSS variables. Instant runtime theme adjustments and dark/light switching without CSS preprocessors.
