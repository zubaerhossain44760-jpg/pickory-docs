SECTION 3

Hooks, Filters & Customizer API

Developer extension surfaces for injecting markup, altering query loops, and customizing token values.

3.1 Action Hook Reference

Key WordPress action hooks fired throughout the lifecycle of the Pickory Theme layout:

Hook Name Parameters Execution Point / Purpose
pickory_theme_before_header None Fires immediately after <body> opening tag (suitable for analytics/announcement bars).
pickory_theme_archive_before_loop $query Fires before the WooCommerce product grid renders on shop & taxonomy archives.
pickory_theme_product_card_badges $product_id Allows custom badge injection (e.g., 'NEW', 'SALE', 'OUT OF STOCK') on the product card.
pickory_theme_after_footer None Fires immediately before the closing </body> tag.

3.2 Hooking the Pickory Product Filter

When Pickory Product Filter is active, Pickory Theme automatically wires up the reactive filter container without requiring shortcodes or widgets. Developers can customize this placement using the pickory_theme_filter_container_id filter:

functions.php — Custom Filter Placement 
<?php
// Customize the DOM mount target for the reactive filter sidebar
add_filter('pickory_theme_filter_container_id', function(string $default_id): string {
    return 'custom-sticky-filter-drawer';
});
