Operating over the dedicated endpoint /wp-json/pickory-filter/v1/products, the Pickory REST subsystem coordinates asynchronous client updates with atomic server-side HTML fragment compilation. Powered by PPFX_Products_Controller and PPFX_Fragment_Renderer with modern WordPress WP_HTML_Tag_Processor attribute injection, the engine renders and swaps product grids, pagination controls, result counters, and loop toolbars with zero Cumulative Layout Shift (CLS) and zero REST URL leakage.

6.1 REST SPECIFICATION

REST Endpoint & Schema (/pickory-filter/v1/products)

Registered in includes/class-ppfx-rest-api.php and managed by PPFX_Products_Controller (includes/rest/class-ppfx-products-controller.php), the endpoint schema defines explicit types, sanitization callbacks, and enum boundaries for all filtering criteria:

REST Argument Schema Type Sanitize Callback / Validation Default / Allowed Values
ppfx_page integer absint Default: 1. Controls catalog pagination offset.
per_page integer min(max(absint($v), 1), $max_per_page) Default: 0 (falls back to WooCommerce default). Filterable ceiling up to 100.
instance_id string sanitize_key Unique widget instance ID. Stripped before query construction and cache hashing.
toolbar_missing boolean rest_sanitize_boolean Default: false. Directs server to compile .ppfx-loop-toolbar if client page originally loaded empty.
ppfx_category string sanitize_text_field Comma-separated category slugs for hierarchical taxonomy filtering.
ppfx_orderby string sanitize_text_field with enum whitelist menu_order, popularity, rating, date, price, price-desc, rand, title, id.
ppfx_order string strtoupper(sanitize_text_field($v)) Enum: '', 'ASC', 'DESC'.
ppfx_min_price
ppfx_max_price		 number max(0.0, (float) $v) Default: 0.0. Non-negative currency boundaries parsed as floats.
ppfx_filter_{tax} string sanitize_text_field Dynamically registered for all active WooCommerce product attributes (e.g. ppfx_filter_color).

Before dispatching queries or computing cache keys, PPFX_Utility::normalize_public_filter_params() transforms public prefixed parameters into clean internal keys: 

// Parameter Normalization & UI State Segregation
$normalized_params = PPFX_Utility::normalize_public_filter_params( $request );
// UI transport keys must never influence query logic or cache identity:
unset( $normalized_params['toolbar_missing'], $normalized_params['instance_id'] );
6.2 ACCESS CONTROL & SECURITY

Nonce Verification & Security

Product filtering endpoints serve public catalog data that must remain fast and cacheable for unauthenticated guests, while remaining strictly protected against Denial-of-Service (DoS) scraping attacks:

Security Layer Implementation Mechanism Defensive Invariant
Permission Callback 'permission_callback' => '__return_true' Permits anonymous catalog browsing. No user session cookies or CSRF nonces required for public reads.
Token Bucket Limiter PPFX_Rate_Limiter::is_rate_limited('ppfx_rate', 80) Caps anonymous requests at 80 requests/minute per client IP using transient buckets. Returns HTTP 429 when exceeded.
Proxy Cache Guard $response->header('Cache-Control', 'no-store') Prevents intermediary reverse proxies (Cloudflare, Varnish) from caching dynamic REST fragment responses against client-specific URLs.
SQL Injection Barrier Strict Type Casting in get_endpoint_args() All inputs are strictly cast to absint, float, or whitelisted against enum dictionaries before reaching the query builder.
6.3 FRAGMENT RENDERING

PPFX_Fragment_Renderer DOM Structure

Located in includes/rest/class-ppfx-fragment-renderer.php, this engine produces an isolated map of HTML fragments corresponding exactly to client-side DOM replacement targets:

Fragment Selector Key Template Helper / Output Source Architectural Responsibility
.woocommerce-result-count Localized text string (e.g. Showing 1–12 of 36 results) Updates catalog counter without triggering a layout reflow. Outputs No products found when count is 0.
.ppfx-loop-toolbar do_action('woocommerce_before_shop_loop') Optional ordering dropdown and result count toolbar. Rendered only when requested via toolbar_missing: true.
.ppfx-products-wrapper woocommerce_product_loop_start() → wc_get_template_part('content', 'product') → woocommerce_product_loop_end() The core catalog product grid. Automatically wrapped in a container stamped with data-ppfx-instance="$instance_id".
.woocommerce-pagination woocommerce_pagination() Standard pagination navigation. Outputs a hidden dummy nav element when results fit on a single page to maintain stable DOM hooks.

To ensure WooCommerce template helpers execute correctly within a REST request context, the renderer executes inside an isolated try ... finally boundary: 

// Isolated Global $wp_query Override
global $wp_query, $post;
$original_query = $wp_query;
$original_post  = $post;

try {
    $wp_query = $query;
    self::setup_loop_props( $query );
    // Capture loop HTML fragments...
} finally {
    $wp_query = $original_query;
    $post     = $original_post;
    wc_reset_loop();
    wp_reset_postdata();
}
6.4 MODERN HTML INJECTION

WP_HTML_Tag_Processor Attribute Injection

Injecting dynamic attributes into captured template markup via regular expressions (e.g. preg_replace) frequently corrupts HTML by mangling nested tags, quotes, or void elements. Pickory leverages WordPress 6.2+'s native streaming engine WP_HTML_Tag_Processor:

PRECISION STREAMING

Deterministic Tag Traversal

Finds the outer wrapper tag via $processor->next_tag(array('class_name' => 'ppfx-products-wrapper')) and sets data-ppfx-instance with zero risk of broken markup.

REST LEAKAGE GUARD

Referrer URL Normalization

Hooks get_pagenum_link and woocommerce_product_add_to_cart_url during fragment rendering to replace REST API endpoints with the actual page referrer URL. 

// Safe Instance Attribute Injection via Tag Processor
$processor = new WP_HTML_Tag_Processor( $captured_products );
if ( $processor->next_tag( array( 'class_name' => 'ppfx-products-wrapper' ) ) ) {
    $processor->set_attribute( 'data-ppfx-instance', $instance_id );
    $captured_products = $processor->get_updated_html();
}
6.5 CLIENT DOM SWAP

Targeted DOM Container Swap

When the REST response arrives on the client, src/js/components/filter-form.js performs targeted fragment replacement rather than an unconstrained innerHTML wipe:

Swap Sequence Target DOM Node Hydration Action
1. Resolution .ppfx-products-wrapper[data-ppfx-instance="..."] Resolves target container using instance ID first, falling back to configured theme selector or standard .products.
2. Replace Wrapper outerHTML Swap Replaces existing products wrapper with incoming fragments['.ppfx-products-wrapper'].
3. Replace Nav .woocommerce-pagination Swaps pagination controls. If results fit on a single page, injects hidden nav anchor so subsequent multi-page queries can remount.
4. Update Counter .woocommerce-result-count Updates text content without altering enclosing toolbar layout or filter toggles.
5. Event Rebind document.dispatchEvent() Fires ppfx:filter-complete and WooCommerce wc_fragments_refreshed to allow theme scripts to rebind tooltips and quickview modals.
6.6 BOOTSTRAP LIFECYCLE

Plugin Bootstrap & Autoload

Located in the root pickory-product-filter.php file, the bootstrap process enforces strict dependency validation and resource efficiency:

  1. HPOS Compatibility: Declares compatibility with WooCommerce High-Performance Order Storage (HPOS) via FeaturesUtil::declare_compatibility('custom_order_tables', __FILE__, true) before WooCommerce initializes.
  2. Version & Path Constants: Defines PPFX_VERSION, PPFX_INDEX_VERSION, PPFX_PLUGIN_DIR, and PPFX_PLUGIN_URL.
  3. Lazy Class Loading: Hooks into plugins_loaded. If WooCommerce is absent, it halts loading immediately and displays an informative admin notice—consuming zero memory on non-eCommerce requests.
  4. Lifecycle Hooks:
    • register_activation_hook: Invokes PPFX_Activator::activate() to generate index tables and schedule the daily expired sales cron.
    • register_deactivation_hook: Unregisters scheduled cron events (ppfx_sync_expired_sales) and clears pending Action Scheduler jobs.
