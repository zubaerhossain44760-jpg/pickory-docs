ENGINEERING STANDARDS

Design Philosophy & Core Tenets

Foundational design constraints followed strictly across all Pickory repositories and releases.

EFFICIENCY

Zero-Bloat Invariant

No jQuery, no multi-megabyte JavaScript bundles, and no runtime CSS compiler dependencies. Standard Web APIs (Custom Events, Fetch, IntersectionObserver) are leveraged natively.

WOOCOMMERCE

HPOS & SQL Isolation

Full compatibility with WooCommerce High-Performance Order Storage (HPOS) and dedicated isolated database schema patterns to avoid database lock contention.

ACCESSIBILITY

WCAG 2.1 AAA Contrast

Strict contrast standards, focus rings, skip-links, and ARIA tree semantics engineered into both documentation portals and production storefront components.
