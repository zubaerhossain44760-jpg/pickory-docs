Frequently Asked Questions

Is Pickory Product Filter fully compatible with WooCommerce HPOS? +

Yes, completely. Pickory Product Filter has native support for WooCommerce High-Performance Order Storage (HPOS) and custom order tables (wp_wc_orders). It does not depend on legacy postmeta tables, ensuring complete compatibility with WooCommerce 9.0+ and modern database architectures.

How does Pickory handle large catalogs with 50,000+ SKUs? +

Pickory uses an indexed flat-table query architecture with grouped taxonomy counts. Rather than executing separate queries per term, attribute counts are resolved in a single consolidated query (reducing database overhead by up to 40% on large catalogs). Additionally, client-side state caching ensures sub-50ms instantaneous filter responses.

How can I customize styling and design tokens without editing core files? +

Pickory exposes standardized W3C CSS custom properties (tokens such as --color-brand, --radius-md, and typography scales). You can override any token safely in your child theme’s style.css or the WordPress Customizer. Your styling customizations persist seamlessly across all future updates.

What details should I provide when submitting a technical diagnostic report? +

For swift investigation, please include your PHP version (PHP 8.0+ is recommended), WordPress & WooCommerce versions, any active object caching plugins (e.g., Redis or Memcached), and relevant excerpts from your WordPress debug log (wp-content/debug.log).

Can I use Pickory Product Filter with custom post meta and ACF fields? +

Yes. Pickory provides comprehensive hook filters (such as filterkit_pre_query and indexing hooks) that allow developers to index custom post meta, Advanced Custom Fields (ACF), and custom hierarchical taxonomies directly into faceted filter controls.

How are updates delivered and licenses activated? +

Updates are delivered directly through the standard WordPress dashboard via the Pickory update API. Once your license key is entered in the Pickory Settings panel, one-click updates and security patches are automatically available.
